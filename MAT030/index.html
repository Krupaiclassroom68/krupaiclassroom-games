1. หลักสำคัญของสมการ

ทำสิ่งเดียวกันทั้ง 2 ข้างของสมการ

เป้าหมายคือทำให้ x อยู่ลำพัง เช่น x + 8 = 15 → ลบ 8 ทั้งสองข้าง → x = 7

➕

2. บวก–ลบ

x − 12 = 20 → x = 32

3x + 5 = 26 → 3x = 21 → x = 7

✖️

3. คูณ–หาร

6x = 54 → หาร 6 ทั้งสองข้าง → x = 9

x ÷ 7 = 8 → คูณ 7 ทั้งสองข้าง → x = 56

↔️

4. มี x ทั้งสองข้าง

5x − 7 = 3x + 15 → 2x = 22 → x = 11

รวบพจน์ x ไว้ข้างเดียว แล้วค่อยจัดค่าคงที่

🧩

5. วงเล็บและหลายขั้นตอน

4(x + 3) = 36 → x + 3 = 9 → x = 6

จะหารสัมประสิทธิ์ก่อน หรือแจกแจงวงเล็บอย่างถูกต้องก็ได้

🔍

6. ตรวจคำตอบ

แทนค่า x กลับในสมการเดิม ถ้าซ้าย = ขวา แสดงว่าคำตอบถูกต้อง เช่น x=7 ใน 3x+5=26 → 21+5=26 ✓
