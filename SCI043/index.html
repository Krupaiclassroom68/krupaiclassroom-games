⚡ แรงและผลของแรง

แรงคือการผลักหรือดึง มี ขนาดและทิศทาง หน่วยนิวตัน (N) แรงทำให้วัตถุเริ่ม/หยุดเคลื่อนที่ เร็วขึ้น ช้าลง เปลี่ยนทิศ หรือเปลี่ยนรูปร่างได้

🎯 แรงลัพธ์

แรงทิศเดียวกัน บวก กัน แรงสวนทาง ลบ กัน และตอบทิศของแรงที่มากกว่า เช่น 30 N → กับ 12 N ← ได้ 18 N →

⚖️ แรงสมดุล

แรงลัพธ์ = 0 N ไม่ได้แปลว่าไม่มีแรง วัตถุอาจหยุดนิ่ง หรือเคลื่อนที่เป็นเส้นตรงด้วยความเร็วคงที่

🌍 แรงในชีวิตประจำวัน

น้ำหนัก คือแรงโน้มถ่วงที่โลกดึงวัตถุลง ส่วนพื้นสามารถออกแรงดันวัตถุขึ้นได้ หนังสือนิ่งบนโต๊ะจึงมีแรงขึ้น–ลงสมดุลกัน

🛞 แรงเสียดทาน

เกิดที่ผิวสัมผัส ต้านการเคลื่อนที่หรือแนวโน้มการเลื่อนสัมพัทธ์ มีทั้ง แรงเสียดทานสถิต ก่อนเริ่มไถล และแรงเสียดทานขณะไถล

🚦 มากที่สุดตอนไหน?

แรงเสียดทานสถิตจะเพิ่มตามแรงที่พยายามทำให้วัตถุเคลื่อนที่ จนมีค่า สูงสุดในชั่วขณะที่วัตถุกำลังจะเริ่มไถล

👟 ปัจจัยที่มีผล

ระดับ ป.5–6 ให้ดู ชนิด/ความขรุขระของผิวสัมผัส และ แรงกดระหว่างผิว เป็นหลัก ผิวที่ยึดเกาะดีหรือกดแน่นขึ้นมักมีแรงเสียดทานมากขึ้น

🛠️ เพิ่ม–ลดแรงเสียดทาน

เพิ่ม: ดอกยาง พื้นรองเท้ามีลาย ผิวหยาบ • ลด: น้ำมันหล่อลื่น ล้อ ลูกปืน ทำผิวให้เรียบ การกลิ้งมักต้านน้อยกว่าการไถล

🔬 การทดลอง

เปลี่ยนทีละปัจจัยและควบคุมอย่างอื่นให้เหมือนเดิม เช่น ศึกษาชนิดพื้น → ใช้กล่องและน้ำหนักเดิม แต่เปลี่ยนเฉพาะพื้น
