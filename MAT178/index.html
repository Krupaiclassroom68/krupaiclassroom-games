📚 ทบทวนสูตรวงกลม ก่อนเริ่ม 25 ข้อ

กำหนดให้ r = รัศมี และ d = เส้นผ่านศูนย์กลาง = 2r • เลือกใช้ π ตามที่โจทย์ระบุ (22/7 หรือ 3.14)

⭕ 1. วงกลมเต็ม

พื้นที่ = πr²

เส้นรอบวง = 2πr = πd

🌗 2. ครึ่งวงกลม

พื้นที่ = ½πr²

ส่วนโค้ง = πr

เส้นรอบรูป = πr + 2r (รวมด้านตรง)

◔ 3. หนึ่งในสี่วงกลม

พื้นที่ = ¼πr²

ส่วนโค้ง = ½πr

เส้นรอบรูป = ½πr + 2r

◕ 4. สามในสี่วงกลม

พื้นที่ = ¾πr²

ส่วนโค้ง = 3/2 πr

เส้นรอบรูป = 3/2 πr + 2r

🛟 5. วงแหวน

พื้นที่แรเงา = π(R² − r²)

R คือรัศมีวงนอก และ r คือรัศมีวงใน

🧠 6. ย้อนหาขนาด

รู้เส้นรอบวง C ⇒ r = C ÷ (2π)

รู้พื้นที่ A ⇒ r = √(A ÷ π)

📐 7. แยกหน่วย

เส้นรอบวงและเส้นรอบรูป ใช้ ซม. หรือ ม.

พื้นที่ใช้ ตร.ซม. หรือ ตร.ม.

🧩 8. เคล็ดลับโจทย์ปัญหา

อ่านก่อนว่าโจทย์ถามพื้นที่ ส่วนโค้ง หรือเส้นรอบรูป และดูว่าต้องรวมด้านตรงหรือไม่

ถ้ารูปไม่กำกับขนาด ให้ใช้ปากกาเขียนรัศมี/เส้นผ่านศูนย์กลางจากโจทย์ลงบนภาพ

⚠️ จำให้ขึ้นใจ: เส้นรอบรูปครึ่งวงกลม, 1/4 และ 3/4 วงกลม ต้องบวกด้านตรง แต่ความยาวส่วนโค้ง ไม่บวกด้านตรง • ในเกมมี 20 ข้อคำนวณ และ 5 ข้อโจทย์ปัญหา
