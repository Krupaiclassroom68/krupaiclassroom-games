📚 ทบทวนการตั้งสมการจากเรขาคณิต

เป้าหมายคือทำให้ x อยู่ตัวเดียว และทำสิ่งเดียวกันกับสมการทั้งสองข้าง

1️⃣ กำหนดตัวแปรก่อน
ให้ x แทนอายุปัจจุบัน หรือจำนวนปีที่ผ่านไป
อ่านก่อนว่าโจทย์ถามอายุของใครและในปีไหน
2️⃣ แปลคำเป็นสมการ
อายุอีก 5 ปี = x + 5
อายุเมื่อ 3 ปีก่อน = x − 3
ใช้เครื่องหมายให้ตรงกับสูตรอายุปัจจุบันและอดีต
3️⃣ แก้สมการทีละขั้น
(x + 27) + x = 53
2x + 27 = 53
2x = 26
x = 13
ทำสิ่งเดียวกันกับทั้งสองข้าง
4️⃣ ตรวจคำตอบกับเรื่องราว
ตรวจอายุในปีที่โจทย์กำหนด ไม่สลับอดีตกับอนาคต
ถ้าซ้ายและขวาเท่ากันจึงผ่าน
💡 เช็กคำตอบได้ด้วยการแทนค่า x กลับในสมการเดิม ถ้าซ้าย = ขวา แสดงว่ามาถูกทาง
